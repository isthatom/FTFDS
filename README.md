# FastTag Fraud Detection System

## Overview
The FastTag Fraud Detection System is a real-time vehicle license plate recognition solution designed to detect fraudulent toll transactions. Built with a Python backend and JavaScript frontend, it combines computer vision and deep learning to deliver accurate, automated plate recognition from live or recorded video feeds.

## Key Features

### Python Backend

- Uses OpenCV and TensorFlow for image processing and deep learning-based plate recognition
- Efficient pipeline for license plate extraction and character recognition
- Scalable architecture suitable for high-throughput environments

### JavaScript Frontend

- Responsive, user-friendly interface built with modern JavaScript frameworks
- Real-time display of recognized plates with associated transaction data
- Easy configuration panel for system monitoring and threshold adjustment

### Real-time Recognition

Real-Time Recognition

- Processes live camera feeds and recorded video streams with low latency
- Maintains high accuracy across varying lighting conditions and plate formats

### Database Integration

- Stores and retrieves recognized plate data from an integrated database
- Supports connection to external systems for downstream analysis and reporting
